# Computational Biomedicine

## About

This repository documents a structured learning trajectory toward a
Computational Biomedical Scientist profile, integrating:

- Molecular Biology and Genomics
- Bioinformatics
- Statistics and Mathematics
- Computer Science and Software Engineering
- Data Science and Machine Learning
- Artificial Intelligence for Genomics

## Objective

The objective is to develop computational depth equivalent to the
requirements of modern biomedical research while maintaining a strong
biological and scientific foundation.

## Learning model

The program is organized into interconnected learning cycles rather
than isolated disciplines.

Each cycle integrates:

→ Biology/Genomics
→ Mathematics/Statistics
→ Computer Science/Software
→ Data Science/AI
→ Scientific Literature

## Languages and tools

Primary languages:

- R — statistics and bioinformatics
- Python — programming, software engineering, machine learning and AI

Core tools and technologies:

- Linux
- Git/GitHub
- Docker/Apptainer
- Nextflow
- HPC
- SQL
- RStudio
- Python
- Machine Learning
- Deep Learning

## Repository structure

```text
01-data-model/
```

Contains the first computational module, focused on data models,
data types, data structures and tabular representations using
genomic examples.

Additional modules will be added as the learning trajectory progresses.

## Philosophy

The goal is not simply to learn programming languages or software.

The goal is to understand how biological questions can be transformed
into computational models, algorithms and reproducible analyses.
